# 🏛️ UNIFORMS: Academic Resource & Facility Reservation Platform

> **UniForms** is an academic full-stack web application designed to streamline institutional space bookings, audiovisual equipment checkout, and administrative approval workflows.

## 📌 Project Overview

Developed during the **'Programação Radical 2025'** event at **UNIVAG**, **UniForms** resolves logistical bottlenecks in academic resource management. The platform provides structured requisition pipelines for professors and a centralized authorization dashboard for department coordinators.

---

## ⚡ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Architecture:** Client-Side Routing, Dynamic DOM Rendering & Form Validations

---

## 🚀 Key Features

* **Multi-Tier Role Access:** Distinct portals and permission boundaries for Faculty (Requesters) and Coordinators (Approvers).
* **Facility & Space Booking:** Calendar-based interface for scheduling classrooms, amphitheaters, and auditoriums without schedule collisions.
* **Equipment Checkout:** Real-time request pipeline for audiovisual hardware (projectors, microphones, adapters).
* **Approval & Audit Dashboard:** Dedicated panel for coordinators to inspect incoming requests, approve allocations, or reject submissions with logged rationale.
